# Contributing Guidelines

Thank you for your interest in contributing to the **Prathamesh Sawarkar Portfolio** project!

## 📜 Code of Conduct
Please review and adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all community interactions.

## 🛠️ How to Contribute

1. **Fork the Repository**
   - Click the "Fork" button in the upper right corner of this repository.

2. **Create a Feature Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make Your Changes**
   - Maintain the **Neobrutalist design language** (pure CSS variables, 3px solid borders, hard shadows, high contrast).
   - Ensure clean, semantic HTML5 and vanilla JavaScript without unnecessary external dependencies.
   - Test responsive behavior across mobile, tablet, and desktop viewports.

4. **Verify Locally**
   ```bash
   npm run dev
   ```

5. **Commit and Push**
   ```bash
   git commit -m "feat: describe your enhancement"
   git push origin feature/your-feature-name
   ```

6. **Submit a Pull Request**
   - Fill out the PR template with clear context, screenshots (if modifying UI), and test steps.
