## Reporting a Vulnerability

Security and privacy are taken seriously across all projects and codebases. If you discover a vulnerability or security issue, please do NOT create a public GitHub issue.

Instead, please report it directly and privately to:
- **Email**: [Prathameshsawarkar1@gmail.com](mailto:Prathameshsawarkar1@gmail.com)

Please provide:
1. Description of the vulnerability.
2. Steps to reproduce the issue or proof-of-concept.
3. Potential impact.

You will receive an acknowledgment within 48 hours and regular updates until resolution.
